# 용산 글모음

손으로 눌러쓴 시와 글을 모아 둔 웹 서비스입니다.

**https://dknife.github.io/YS/**

- `/` — 시 모음 (원고 사진 + 옮겨 적은 글)
- `/book.html` — 자서전 「나의 이야기」, 쪽마다 그림이 딸린 그림책.
  1쪽은 그림 위에 제목을 얹은 표지, 2쪽부터는 왼쪽에 그림 오른쪽에 그 쪽의 글이 놓이고
  버튼·좌우 화살표 키·스와이프로 한 쪽씩 넘깁니다. 좁은 화면에서는 그림 아래에 글이 옵니다.

디자인은 `DESIGN.md` (Sutera 스타일: 미니멀 흑백 + 오렌지 액센트 `#FA5D29`) 를 따릅니다.

## 구조

```
YS/
├─ index.html            # 시 모음
├─ book.html             # 나의 이야기 (책)
├─ assets/
│  ├─ style.css          # 공통 테마
│  ├─ app.js             # 시 모음 동작
│  ├─ book.css, book.js  # 책 동작
│  ├─ thumbs/            # 목록용 축소 이미지 (긴 변 900px)
│  ├─ view/              # 상세보기용 이미지 (긴 변 2000px)
│  └─ book/              # 「나의 이야기」 쪽 그림 (001.jpg ~ 033.jpg)
├─ data/
│  └─ poems.json         # 시 목록과 분류
├─ 시/
│  ├─ *.jpg              # 원고 사진
│  └─ *.txt              # 사진에서 옮겨 적은 글
└─ 나의 이야기/
   └─ 할아버지이야기_텍스트.txt   # 책 본문 (그림 원본 등 그 외 파일은 저장소에서 제외)
```

## 시 고치기 / 추가하기

`시/<제목>.txt` 를 고치면 사이트에 그대로 반영됩니다.
첫 줄이 제목과 같으면 제목 줄로 표시되고 나머지가 본문이 됩니다.

새 시를 추가하려면

1. `시/` 에 `<제목>.jpg` 와 `<제목>.txt` 를 넣습니다.
2. `powershell -ExecutionPolicy Bypass -File tools\make-images.ps1` 로 축소 이미지를 만듭니다.
   (EXIF 회전은 이미지에 직접 반영되고 태그는 제거됩니다.)
3. `data/poems.json` 의 `poems` 에 `{ "name": "<제목>", "category": "가족" }` 을 추가합니다.
   분류는 가족 / 기억 / 자연 / 황혼 중 하나입니다.

## 책 본문 고치기

`나의 이야기/할아버지이야기_텍스트.txt` 한 파일이 책의 원본입니다. 표기 규칙은

| 표기 | 뜻 |
|------|-----|
| `#3` | 3쪽 시작 |
| `- 제목` | 제목 (표지) |
| `-- 작은 제목` | 작은 제목 (장 표제지) |
| 빈 줄 | 문단 구분 |
| 두 칸 이상 들여쓴 줄 | 인용 (노랫말·시) |

제목/작은 제목만 있는 쪽은 표지·장 표제지로 자동 처리되고, 목차 버튼도 그 쪽들로 만들어집니다.
쪽 번호를 바꾸거나 쪽을 추가해도 코드는 고칠 필요가 없습니다.

## 책 그림 바꾸기 / 추가하기

`n` 쪽에는 `assets/book/00n.jpg` 그림이 자동으로 붙습니다.
세로로 긴 3:4 그림이 가장 잘 맞지만 가로 그림도 그대로 받아 줍니다.
그림이 없는 쪽은 그 자리가 조용히 비어 있을 뿐 나머지는 그대로 동작합니다.

원본 그림은 `나의 이야기/` 에 두고 (파일 이름 끝의 세 자리 숫자가 쪽 번호)

```
python3 tools/make-book-images.py
```

를 돌리면 `assets/book/` 의 웹용 이미지가 다시 만들어집니다.
긴 변 1024px, 품질 78 의 점진(progressive) JPEG 으로 줄여 한 장에 200KB 안팎이 됩니다.
원본은 용량이 커서 저장소에 올리지 않고, 만들어진 jpg 만 올립니다.
(Pillow 가 필요합니다 — `python3 -m pip install Pillow`)
