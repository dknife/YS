# 용산 글모음 — 책으로 엮기

사이트에 있는 글을 그대로 읽어 한 권의 그림책 PDF 로 만듭니다.

```
sh latex/build.sh
```

를 돌리면 `latex/main.pdf` 가 나옵니다. (116쪽, 200×250mm)

## 어떻게 생겼나

어린이가 함께 넘겨 볼 수 있도록 그림을 앞세운 그림책 꼴입니다.

- **앞표지** — 그림이 종이 끝까지 차고 그 위에 제목 판을 얹습니다.
- **하나. 나의 이야기** — **왼쪽(홀수) 면에 그림 한 장 가득, 오른쪽 면에 그 쪽의 글**.
  그림을 먼저 보고 글을 읽는 그림책의 순서 그대로입니다.
  한 자락은 늘 홀수 쪽에서 그림으로 열립니다.
  장이 바뀌는 곳(유년기·청년기·장년기·노년기)도 같은 짜임입니다.
  노랫말은 크림색 상자에 담아 본문과 결을 다르게 두었습니다.
- **둘. 시 모음** — 이야기와 같은 짜임입니다.
  **왼쪽 면에 분류 딱지·제목과 눌러쓴 원고 사진, 오른쪽 면에 옮겨 적은 글.**
  분류마다 딱지 색이 다릅니다 (가족 자두 / 기억 하늘 / 자연 초록 / 황혼 금빛).

  시는 **왼쪽 제목 바로 아래, 곧 사진이 시작하는 높이에서 시작**합니다.
  제목 칸의 높이를 `\ysheadgap` (32mm) 으로 못 박아 두어 두 면의 시작 높이가 맞습니다.
  긴 시는 사진 아래에 해당하는 자리까지 내려쓰고, 그래도 모자라면
  길이에 맞춰 글자를 조금 작게 씁니다 (`make-tex.py` 의 `SIZE_LADDER`, 13pt~10pt).
  덕분에 시 스물두 편이 모두 한 펼침 안에 들어갑니다.
- 쪽 번호는 바깥쪽 아래에 주황 동그라미로 크게 붙여 아이가 쪽을 찾기 쉽게 했습니다.

글자는 큼직하게(본문 15pt), 줄 사이는 넉넉하게(28pt) 두었습니다.
종이 바탕은 아주 옅은 크림색이라 오래 봐도 눈이 덜 부십니다.

## 무엇으로 만드나

| | |
|---|---|
| 엔진 | XeLaTeX |
| 글꼴 | 본문·제목 KoPub돋움, 시와 노랫말 KoPub바탕 |
| 판형 | 200 × 250 mm |
| 주조색 | 사이트와 같은 주황 `#FA5D29` |

글꼴은 [KoPub 서체](https://www.kopus.org/biz-electronic-font2/)이며 무료로 배포됩니다.
설치되어 있지 않으면 `preamble.tex` 의 `\setmainfont` 줄을 가진 글꼴로 바꾸면 됩니다.

## 짜임

```
latex/
├─ main.tex          # 책의 뼈대 — 표지, 여는 글, 차례, 두 부
├─ preamble.tex      # 글꼴·색·판형과 책을 이루는 조각들
├─ build.sh          # 원고 옮기기 + XeLaTeX 두 번
├─ tools/
│  └─ make-tex.py    # 원고(txt/json) -> tex 조각
└─ generated/        # 자동으로 만들어지는 tex (직접 고치지 말 것)
```

## 글을 고치면

책은 사이트와 **같은 원고 파일**을 읽습니다.

- `나의 이야기/할아버지이야기_텍스트.txt`
- `시/<제목>.txt` 와 `data/poems.json`

그래서 글을 고치고 `sh latex/build.sh` 를 다시 돌리면 사이트와 책이 함께 바뀝니다.
따로 옮겨 적을 곳은 없습니다.

그림도 사이트와 같은 것을 씁니다. 이야기 그림은 `assets/book/`,
시 원고 사진은 `assets/view/` 에서 가져옵니다.
(시 사진은 파일 이름이 한글이라 XeLaTeX 이 찾지 못하므로
`make-tex.py` 가 번호를 붙여 `latex/images/poems/` 로 옮겨 둡니다.)

## 알아 둘 것

이야기 그림의 원본이 765×1024 이라 인쇄용으로는 촘촘하지 않습니다.
화면으로 보거나 집에서 뽑아 보기에는 넉넉하지만, 인쇄소에 넘길 생각이라면
그림을 더 큰 크기로 다시 받아 `assets/book/` 를 채우는 편이 좋습니다.
